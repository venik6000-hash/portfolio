# Портфолио Никиты Тесленко

Одностраничный сайт: главная с доком, экран проектов с карточками и экран «обо мне».
Статика без сборки: `index.html`, `styles.css`, `script.js` (ES-модуль) и данные в `data/content.js`.

Сайт: https://venik6000-hash.github.io/portfolio/

## Запуск

```bash
python3 -m http.server 4173
```

Открыть http://127.0.0.1:4173/. Прямые ссылки: `#projects`, `#projects/<slug>`, `#about`.

Для скриптов из `tools/` нужен Node.js и один раз `npm install` (ставит `playwright-core`). Браузер скрипты берут из кэша Playwright или из установленного Google Chrome.

## Как добавить проект

1. Добавить объект в массив `projects` в `data/content.js`: `slug`, `title`, `dockLabel`, `icon`, `description`, `media`, при необходимости `url`. Порядок в массиве задаёт порядок карточек и плиток в доке.
   - `icon.wave` — цвет волны перехода: приглушённая пастель в тон плитки (светлота 62–80 %, насыщенность 25–55 %), а не сам цвет плитки.
   - `media.tone` — цвет фона картинки; им закрашено место под неё, пока она грузится.
2. Нарисовать плитку `assets/icons/<slug>.svg`: квадрат 64×64 без скруглений (углы скругляет CSS), плоская заливка и один знак. Тёмных плиток в ряду не больше двух-трёх и не подряд: на чёрном фоне они теряют силуэт.
3. Положить сырой скриншот в `assets/projects/raw/` (папка не хранится в git).
4. Описать сцену в `assets/projects/mockups.json`: устройство, угол, фон, путь к скриншоту. Параметры перечислены в шапке `tools/mockup.html`.
5. Собрать картинку карточки:

   ```bash
   node tools/mockup.mjs <slug>
   ```

   Получится `assets/projects/<slug>.jpg`, 2240×1260.

Элемент `description` может быть строкой (абзац) или объектом `{ text, links: [{ label, href }] }` (текст и ссылки через запятую). Тексты пишутся обычными пробелами и дефисами: неразрывные пробелы после предлогов, перед тире и эмодзи расставляет `typograph()` в `script.js` при отрисовке.

## Картинка для превью ссылки

```bash
node tools/og.mjs
```

Скрипт снимает главную и пишет `assets/og.jpg` (1200×630). Пересобирать после смены аватара, имени или заголовка. `og:url`, `og:image` и `canonical` в `index.html` указывают на адрес GitHub Pages: при переезде на свой домен заменить их там.
